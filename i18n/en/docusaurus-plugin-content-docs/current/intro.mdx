# Welcome to the DM Loremind documentation

**DM Loremind** is a self-hosted tabletop RPG assistant that combines campaign management, character sheets, lore
and local or cloud AI to help you prepare your games.

## Key features

<IconFeatureList>
  <IconFeature Icon={Dices} title="Multi-system">manage several campaigns each with their own TTRPG rules.</IconFeature>
  <IconFeature Icon={Sparkles} title="Local or remote AI">Ollama locally, or 1min.ai, Mistral, Gemini and OpenRouter in the cloud.</IconFeature>
  <IconFeature Icon={ShieldCheck} title="100% self-hosted">content is stored in your installation; cloud AI sends relevant context to the selected provider.</IconFeature>
  <IconFeature Icon={Download} title="Desktop or Docker">Windows MSI, Linux AppImage, or Docker for a server.</IconFeature>
  <IconFeature Icon={RefreshCw} title="Updates">desktop release notifications, or optional automatic updates with Docker Watchtower.</IconFeature>
</IconFeatureList>

## Architecture

DM Loremind is made up of three services that communicate through Docker Compose:

- **Core** — Java/Spring Boot backend (business API, Postgres + MinIO persistence).
- **Brain** — Python/FastAPI service dedicated to AI (LLM orchestration, RAG).
- **Web** — Angular user interface.

Optionally, a fourth **Ollama** service can be started to serve the LLM models locally.
