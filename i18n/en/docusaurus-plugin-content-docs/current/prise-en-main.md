# Prepare and run your first game

This walkthrough starts with an installation open in your browser. The desktop
default address is `http://localhost:8080`; the Docker installer usually uses
`http://localhost:8081`.

You can create and play your content manually without configuring AI. Generation,
PDF imports and chat require an [AI provider](/docs/assistant-ia/fournisseurs).

## 1. Choose a starting point

| Your goal | Start with |
|---|---|
| Run a one-shot tonight | A campaign with a few scenes |
| Build a reusable setting | A Lore, folders and templates |
| Use custom character sheets | A game system with PC / NPC / Enemy templates |
| Adapt a PDF adventure | A campaign, then PDF import |

Lore and game system associations are optional. However, choose your system
before filling many character sheets: it defines their fields.

## 2. Create a campaign

Open **Campaign → New Campaign**. Enter its name, pitch and player count.
Optionally select a setting and a system, then confirm.

![Campaign creation form, shown in French](/img/screenshots/guides/creation-campagne.jpg)

Start with **Scene** or the **+** beside **Scenes** in the tree. A title, a situation
and something the players can do are enough for a first scene. Add arcs and chapters
as the adventure grows. See [Create and organise a campaign](/docs/campagne/creation-campagne).

## 3. Prepare playable content

1. Create two or three scenes: a hook, an obstacle and a possible outcome.
2. Fill **player narration** and keep secrets in **GM notes**.
3. Add the NPCs you need, and bestiary enemies for combat encounters.
4. Connect scenes with [narrative branches](/docs/campagne/branches).
5. Check **Next steps** on the campaign and use **Fix** to address reported gaps.

You can also create a [quest](/docs/campagne/quetes) to track an objective.
[Guided preparation](/docs/campagne/preparation) checks structure and some references;
it does not assess the quality of your story.

## 4. Open your group's playthrough

On the campaign, open **My playthroughs**. Use an existing playthrough or create
one, then add this group's PCs. A campaign contains the scenario; a **playthrough**
contains the game state for one group.

From that playthrough, start a session or resume the active one.
[Session mode](/docs/campagne/mode-seance) brings together the journal, scenes,
character sheets, dice and game resources.

## 5. During and after the session

Pin the current scene from the **Scenes** tab. Record decisions and events in the
journal. Update quests, facts and clocks to reflect what happened.

Complete the journal before ending the session: it becomes read-only afterwards.
Next time, **Prepare the next session** on the playthrough helps you pick up the story.

Finally, create a [ZIP backup](/docs/configuration/sauvegardes) from Settings.
The [PDF](/docs/export/pdf) is a preparation booklet; the ZIP allows you to
reimport your data into Loremind. Screenshots in these guides use the French UI.
