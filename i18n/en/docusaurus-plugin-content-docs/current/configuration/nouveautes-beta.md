# What's new on the beta branch

This page covers additions on **beta** after stable **1.0.3**: the full writing
mentor at **1.1.0-beta**, followed by session, mobile and tablet workflows at
**1.2.0-beta**, including recent network fixes. Availability depends on the
installed version.

## Prepare and write

- **[Writing mentor](/docs/campagne/mentor-ecriture)**: lightbulbs explain fields
  with questions, examples and common pitfalls.
- **[Editor review](/docs/campagne/relecture-editeur)**: advice about choices,
  stakes, pacing and narration links to the relevant passage.
- **[Five-room dungeon](/docs/campagne/methode-cinq-salles)**: nine steps to prepare
  a chapter and five scenes, optionally connected in sequence.

All three work **without AI**, alongside chat and generation features.

## Find and run a session

The campaign home has a **Play** block: resume an active session, choose a
playthrough to start one, or create a playthrough first. The tree includes
**Playthroughs**. The **Session in progress** shortcut returns to the game from
other pages, including the compact mobile top bar.

In [session mode](/docs/campagne/mode-seance), **Rules** displays the associated
system with highlighted search, collapsible sections, contents and pins.
**Ask AI** prepares a question for you to review before sending.

## Use a phone or tablet

[Compact navigation](/docs/navigation#phone-and-tablet-beta) replaces permanent
sidebars with separate main menu and tree drawers. Forms, dialogs and session
panels adapt to small screens.

On **desktop installations**, [tablet access](/docs/configuration/acces-tablette)
authorises a local-network browser with a QR code or six-digit code. Settings
remain restricted to the PC. On Windows, **Network check** helps verify the
network profile and firewall permission.

Desktop pairing is separate from Docker: responsive UI works in both modes,
but Docker does not have this pairing connector.

For the prerelease channel, see [Patreon private beta](/docs/configuration/beta-patreon).
Back up content before switching versions; returning to stable does not restore
an earlier data snapshot.
