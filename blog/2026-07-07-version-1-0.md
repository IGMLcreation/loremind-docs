Après 4 mois de travail assez acharné, j'ai enfin mis en place toutes les fonctionnalités de base que
je souhaitais voir dans l'application : la V1 est donc officiellement de sortie !

{/* truncate */}

L'application permet de couvrir le cycle complet d'une préparation de JDR :

## Construction de votre univers : partie Lore

De ce coté là, pas de grosse nouveauté mis à part le template building pour vos différentes pages. Mettez les en forme comme vous le souhaitez pour adapter
à vos envies ! différents types de champs dispo : texte, image, liste de valeurs ou encore tableau.
Voici un exemple de ce que ça donne dans l'appli :

![template_building](/img/screenshots/devlog/07-07-26_post/template_building.png)

![apercu_page](/img/screenshots/devlog/07-07-26_post/apercu_page.png)

## Construction de votre campagne

- Préparation de votre campagne avec toutes les différentes parties :
  - Les arcs principaux, format "libre" ou format plus linéaire.
  - Les chapitres / quêtes selon ce que vous avez choisi.
  - Créer librement des quêtes sans être contraint de fixer ça dans un chapitre / arc.
  - Création de scènes pour vos différentes quêtes et qui comprennent la possibilité d'y attacher

- les cartes que vous aurez créer (Dungeon Alchemist + Dungeon Draft pour le moment disponibles) :
  
![Battlemaps](/img/screenshots/devlog/07-07-26_post/battlemaps_dans_scenes.png)
  
- Possibilité de créer des parties avec différentes séances ; gérer des "horloges de menace"
(horloge qui avance ou recule en fonction des actions de vos joueurs, comme par exemple l'horloge
dans la campagne D&D Le Carnaval de Sorcelume qui permet de suivre l'ambiance du carnaval). Ces dernières
sont dispos dans la partie ou les différentes séances. Pleins de nouveautées sont disponibles comme par exemple
le fait de pouvoir épingler une scène pour savoir où en sont vos joueurs ; générer un résumé de votre séance précédente
grâce aux notes de cette dernière et à l'IA : 
![Horloges](/img/screenshots/devlog/07-07-26_post/horloge.png)
![Resume seance](/img/screenshots/devlog/07-07-26_post/resume_seance.png)

- Très important à mes yeux : l'export pour FoundryVTT. Un module a été développer spécialement pour ce dernier
afin de pouvoir faire transiter des données entre les deux applis (pour le module foundry, ce rendre sur [Github](https://github.com/IGMLcreation/loremind-importer)).
Le module permet d'exporter des acteurs et leurs structures à partir de votre système de jeu foundry pour les importer et les adapter dans loremind :

![Export_acteur_foundry](/img/screenshots/devlog/07-07-26_post/export_acteur_foundry.png)

![Import_acteur_foundry](/img/screenshots/devlog/07-07-26_post/import_structure_ennemie.png)

Je pense que le systeme est à améliorer, mais cela fait une bonne base. Il vous suffit ensuite dans 
votre campagne d'importer les ennemies issus de foundry. Ci-dessous un exemple avec un import pour
le système Nimble que j'affectionne beaucoup :

![Import_monstre_loremind](/img/screenshots/devlog/07-07-26_post/import_monstres.png)

![Krogg_exemple](/img/screenshots/devlog/07-07-26_post/krogg_exemple.png) 

Grâce à ça, vous pouvez exporter vos scènes directement avec battlemap + ennemis rattachés et foundry
sera capable de vous lier les deux à l'import ! J'en dirai d'avantage dans la documentation.

- J'ai également mis en place un graphe automatique qui lie vos différents éléments (PNJ, quêtes, scènes, pages de lore) 
grâce au champs "Pages de lore liées" :

![graphe_lore](/img/screenshots/devlog/07-07-26_post/graphe.png)

Et enfin : Un export PDF pour ceux qui souhaitent jouer sur table et non sur VTT : 
- Export des différentes pages de lores.
- Export de toute la campagne.
- Export du bestiaire avec les champs associés.... :

![pdf_export](/img/screenshots/devlog/07-07-26_post/PDF_export.png)

La 1.0 n'est pas une fin et l'application va continuellement s'améliorer.
