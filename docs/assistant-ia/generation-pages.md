# Générer le contenu des fiches

Un [fournisseur IA configuré](/docs/assistant-ia/fournisseurs) permet de proposer
le contenu des fiches. Les commandes diffèrent entre les pages de Lore et les
entités de campagne ; la validation finale reste explicite.

## Page de Lore existante

1. Ouvrez la page en **édition**, puis **Assistant IA**.
2. Vous pouvez discuter de la fiche ou lancer **Remplir automatiquement tous les champs**.
3. Le panneau se ferme pendant le remplissage ; les suggestions apparaissent
   directement dans les champs **Texte** du formulaire.
4. Relisez et corrigez les valeurs, puis cliquez sur **Sauvegarder** pour les conserver.

:::warning[Le remplissage peut remplacer du texte]
Une suggestion non vide remplace la valeur courante du champ dans le formulaire.
Une suggestion vide conserve sa valeur. Pour garder un passage, copiez-le avant
la génération ou quittez avec **Annuler** pour retrouver la dernière version enregistrée.
:::

Les blocs **Image**, **Liste clé/valeur** et **Tableau** ne sont pas remplis par
cette commande. La génération s'appuie sur la page enregistrée : sauvegardez
au préalable les informations que vous voulez lui donner comme contexte.

## Nouvelle page avec l'assistant

Dans [Créer une page](/docs/lore/creation-page), choisissez le titre, le template
et le dossier, puis **Créer avec l'IA**. Décrivez votre intention dans l'assistant
et utilisez les étapes de validation pour créer la fiche. Relisez ensuite le
contenu en édition. Ce wizard utilise un échange temporaire ; il ne remplace pas
l'historique du [chat habituel](/docs/assistant-ia/conversations).

## Arcs, chapitres et scènes : Étoffer avec l'IA

Dans l'éditeur, ouvrez **Étoffer avec l'IA**. Saisissez éventuellement une instruction
(« garder un ton inquiétant, proposer une issue sans combat »), puis **Générer**.

Le panneau présente chaque champ proposé, sa valeur actuelle et sa proposition :

1. cochez les champs à garder et décochez les autres ;
2. utilisez **Appliquer la sélection** pour remplir le formulaire ;
3. ajustez le texte puis **Sauvegarder** la fiche.

**Régénérer** demande de nouvelles propositions. L'application d'une sélection
remplit les champs ; elle ne sauvegarde pas à elle seule la fiche.

## Générer des scènes pour un chapitre

Le panneau **Générer des scènes** permet de préciser une intention et un nombre
souhaité. Relisez les brouillons, cochez ceux à conserver puis cliquez sur la
commande de **création de la sélection**. Ici, la validation **crée les scènes**
dans le chapitre : ouvrez-les ensuite pour les affiner, définir leurs branches
et vérifier les références.

## Obtenir des propositions utiles

Enregistrez quelques faits de départ, reliez les pages de Lore pertinentes et
associez le système de JDR à la campagne. Demandez une portée précise : une
ambiance, deux enjeux, trois choix avec conséquences. Vérifiez les secrets,
les règles et les noms avant de valider ; une réponse IA reste une proposition.
