# Navigation et recherche globale

La barre principale donne accès au **Lore**, aux **Campagnes**, aux **Systèmes de
JDR** et aux **Paramètres**. Dans un univers ou une campagne, un second volet
présente son arborescence et ses commandes de création.

## Retrouver une fiche

Cliquez sur **Recherche globale** ou utilisez **Ctrl + K** (ou **Cmd + K**).
Saisissez **au moins deux caractères**. La recherche porte sur les univers,
dossiers, templates et pages de Lore, ainsi que les campagnes, PNJ, PJ, ennemis,
tables aléatoires et catalogues d'objets.

![Recherche globale et résultats typés](/img/screenshots/guides/recherche-globale.jpg)

Le type indiqué sous le titre permet de distinguer des résultats portant le même
nom. Les pages de Lore apparaissent avant les ressources de campagne, puis les
dossiers, templates et racines.

| Touche | Action |
|---|---|
| **↑ / ↓** | Sélectionner le résultat précédent / suivant |
| **Entrée** | Ouvrir le résultat sélectionné |
| **Échap** | Fermer la recherche |

Cette palette recherche vos entités enregistrées. Pour poser une question sur le
contenu d'un PDF, utilisez l'[Atelier IA](/docs/campagne/notebooks).
Les arcs, chapitres et quêtes restent accessibles depuis l'arborescence de campagne.

## Utiliser l'arborescence

- Le **chevron** déplie ou replie une branche ; le **nom** ouvre la fiche.
- Les boutons **+** créent un élément dans le contexte de la branche choisie.
  Cela évite de sélectionner à nouveau son parent.
- Le titre du volet ramène à l'accueil de l'univers ou de la campagne.
- Les [pastilles de préparation](/docs/campagne/preparation) signalent les manques
  d'une scène et remontent vers ses parents.

## Réordonner et déplacer

Dans les branches qui le permettent, glissez un élément pour changer son ordre,
ou déposez-le sur un parent compatible pour le déplacer. Les possibilités dépendent
du type : pages vers dossiers de Lore, scènes vers chapitres, chapitres vers arcs,
PNJ et ennemis vers leurs dossiers. Un emplacement incompatible refuse le dépôt.

L'ordre de l'arbre est distinct du placement visuel dans les graphes. Déplacer
un nœud dans la carte des scènes modifie sa position à l'écran, pas l'ordre narratif
de la liste. Pour modifier les sorties d'une scène, voir
[Branches narratives](/docs/campagne/branches).

## Langue

Dans **Paramètres → Langue de l'interface**, choisissez français ou anglais.
La modification est immédiate et mémorisée **sur cet appareil**. Les captures de
ces guides montrent l'interface française ; le placement des commandes est identique
dans la version anglaise.

## Téléphone et tablette (bêta)

Sur un écran compact, la barre haute remplace les volets permanents :

- **Ouvrir le menu** affiche Lore, Campagne, Systèmes de JDR et Paramètres ;
- **Ouvrir l'arborescence** affiche l'univers ou la campagne en cours ;
- la **loupe** ouvre la recherche globale ;
- le raccourci **Séance en cours** apparaît lorsqu'une séance est active. Avec plusieurs séances, il permet de choisir laquelle rejoindre.

![Arborescence de campagne dans le tiroir mobile](/img/screenshots/beta/navigation-mobile.jpg)

Le menu et l'arborescence s'ouvrent chacun dans un tiroir. Touchez le fond assombri,
le bouton de fermeture ou **Échap** pour le refermer. Choisir une page referme aussi
le tiroir. Les **+** contextuels restent disponibles dans l'arbre.

Sur grand écran, **Replier l'arborescence** réduit le volet secondaire ; **Déplier
l'arborescence** le restaure. Pour utiliser le bureau depuis un autre appareil,
configurez l'[accès tablette](/docs/configuration/acces-tablette). La présentation
mobile seule ne connecte pas la tablette au PC.
