# Méthode guidée : Enquête en nœuds

:::info[Bêta 1.4.0]
Cette méthode est disponible depuis **1.4.0-beta**, sans IA ni clé API.
:::

L'enquête prépare plusieurs moyens de découvrir la même vérité : une accroche,
trois pistes qui se recoupent, une conclusion et une scène de relance. Les joueurs
peuvent ainsi changer de piste quand une approche ne fonctionne pas.

Depuis **Méthode guidée** sur l'accueil de campagne, choisissez **Enquête en
nœuds**, puis **Commencer**. Pour le placement et les brouillons, voir
[Choisir une méthode guidée](/docs/campagne/methodes-guidees).

## Les neuf étapes

| Étape | Ce que vous préparez |
|---|---|
| **Placement** | Arc linéaire existant ou nouvel arc |
| **Le mystère** | Nom de l'enquête, vérité cachée et enjeux |
| **L'accroche** | Évènement ou rencontre qui lance l'affaire, premières pistes |
| **Première piste** | Lieu, personne ou évènement ; contenu, indices et secrets |
| **Deuxième piste** | Une autre source, ses indices et ses secrets |
| **Troisième piste** | Une troisième entrée pour varier les approches |
| **La conclusion** | Révélation ou confrontation, et conséquences possibles |
| **La relance** | Ce que déclenche le MJ si la table piétine, avec de nouvelles pistes |
| **Récapitulatif** | Chapitre, six scènes typées et liens qui seront créés |

Pour les trois pistes, les types proposés sont **Lieu**, **PNJ** ou **Événement**.
Les choix initiaux varient pour encourager des sources différentes. Les noms
proposés se modifient comme les autres réponses.

## Le réseau créé

**Créer l'aventure** ajoute un chapitre et **six scènes**, avec **douze liens** :

- l'accroche ouvre les trois pistes ;
- les pistes forment une boucle : 1 → 2 → 3 → 1 ;
- chacune mène à la conclusion par un lien **Indice** ;
- la relance renvoie vers les trois pistes.

Les autres connexions sont des liens **Piste**. La conclusion possède ainsi trois
scènes d'accès distinctes. Dans la [carte des scènes](/docs/campagne/branches),
remplacez les libellés génériques par les indices concrets et ajustez les chemins
à votre intrigue.

La vérité du mystère est placée dans les **notes MJ du chapitre**. Les secrets
des trois pistes deviennent les **notes secrètes MJ** des scènes ; les indices
décrits sont conservés dans **Choix et conséquences**. Cette méthode ne remplit
pas automatiquement le champ Histoire cachée de l'arc.

## Faire vivre l'enquête

La relance est une scène de type **Événement**, à déclencher lorsque cela sert
la partie : un témoin se présente, l'adversaire riposte, une menace progresse.
Elle n'est pas déclenchée automatiquement par le temps ou par un échec.

Le réseau donne des chemins ; rédigez ce que les personnages peuvent réellement
apprendre dans chaque piste. La [relecture](/docs/campagne/relecture-editeur)
signale notamment les révélations trop peu accessibles et les sources toutes du
même genre.
