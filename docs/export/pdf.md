# Livret PDF de campagne

Sur la **page de la campagne**, le bouton **« Exporter en PDF »** génère un
**livret mis en page façon livre de JdR** — pour préparer hors écran, jouer sur
table sans ordinateur, partager un support papier ou archiver une campagne
terminée. Le fichier produit porte le nom de la campagne
(`ombre-du-nord.pdf`).

## Contenu du livret

Dans l'ordre :

1. **Couverture** — titre, description, métadonnées (« X scènes · Y quêtes ·
   Z PNJ… ») et date d'export ;
2. **Sommaire paginé** ;
3. **Structure narrative** — arcs → chapitres et [quêtes](/docs/campagne/quetes)
   → scènes, avec un en-tête courant pour se repérer ;
4. **Quêtes** — les quêtes transverses, sans doublon avec la structure ;
5. **Personnages non-joueurs** — groupés par dossier ;
6. **Bestiaire** — groupé par dossier, avec le niveau de chaque fiche ;
7. **Tables aléatoires** — avec leur formule de dés ;
8. **Lore** — les pages de l'univers associé, groupées par dossier *(si un
   Lore est lié à la campagne)*.

## Les encadrés

Le livret sépare visuellement ce qui se lit et ce qui se cache :

- **« À lire aux joueurs »** — la narration à voix haute des scènes ;
- **notes secrètes MJ** — secrets, développements, conséquences (encadré
  distinct, pour ne jamais les lire par accident) ;
- **« Combat »** — difficulté et ennemis de la rencontre, reliés au bestiaire ;
- **pièces explorables** — pour les scènes en mode donjon : description,
  ennemis, butin, pièges, notes MJ et sorties numérotées, pièce par pièce.

## Battlemaps

Les [battlemaps des scènes](/docs/campagne/arcs-chapitres-scenes) sont rendues
avec leur légende (« Battlemap — Jour », « Battlemap — Étage 1 »…), variantes
incluses.

:::note
Les battlemaps **vidéo** ne peuvent pas être rendues dans un PDF — seules les
images sont incluses.
:::

## Limites

- Les images sont **redimensionnées et recompressées** pour garder un PDF
  raisonnable ; sur une grosse campagne le fichier peut malgré tout peser
  plusieurs Mo, et la génération prendre quelques secondes (le bouton affiche
  **« Génération… »**).
- Le livret couvre **toute la campagne** — il n'y a pas (encore) de sélection
  de périmètre comme pour l'[export Foundry](/docs/export/foundry).
